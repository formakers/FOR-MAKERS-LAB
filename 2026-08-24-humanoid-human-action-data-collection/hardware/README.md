# Hardware Notes

이 폴더는 센서 장갑의 하드웨어 설계 메모를 저장하기 위한 공간입니다.

## 권장 개발 순서

1. Flex Sensor 1개 + ESP32
2. Flex Sensor 5개
3. IMU 추가
4. 버튼/LED 추가
5. 배터리/충전 회로 추가
6. 3D 프린팅 케이스 제작
7. Wi-Fi/BLE 무선화

## 주의

- ESP32 ADC 입력 전압 범위를 초과하지 않도록 확인하세요.
- 배터리와 레귤레이터 정격을 반드시 확인하세요.
- Li-Po 충전 회로는 보호 기능이 있는 모듈 사용을 권장합니다.
- 실제 GPIO 번호는 사용 중인 ESP32 보드 데이터시트 기준으로 확정하세요.
