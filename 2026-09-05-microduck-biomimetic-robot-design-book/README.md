# MicroDuck Biomimetic Robot Design Book

실제 오리의 움직임을 출발점으로 MicroDuck 형태의 이족보행 로봇을 분석한
메이커용 설계 학습 자료입니다.

핵심 주제는 실제 오리와 로봇의 관절 매핑, DYNAMIXEL 모터 배치, 축 방향과
회전 범위, 관절 각도와 동작, 보행 시퀀스, 센서 기반 제어, 제어 파라미터
튜닝, 응용 동작, 모션 리타게팅과 Physical AI입니다.

전체 본문은 `BOOK.md`에서 볼 수 있으며, 관련 시스템 설계도는 `images/`
폴더에 정리되어 있습니다.

주의: 본 프로젝트의 일부 모터 배치, 관절 수치와 제어값은 공식 MicroDuck
사양이 아니라 교육적 이해를 위한 개념 예시입니다.
