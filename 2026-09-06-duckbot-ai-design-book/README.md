# DuckBot AI Design Book

**프로젝트:** 덕구봇(DuckBot) — AI와 함께 설계하는 새로운 오리 로봇  
**날짜:** 2026-09-06  
**채널/랩:** FOR MAKERS LAB

이 프로젝트는 MicroDuck 사진과 구조 분석에서 출발해, AI와 대화를 통해 새로운 이족 오리 로봇 **덕구봇(DuckBot)** 콘셉트로 발전한 과정을 정리한 기록입니다.

## 핵심 흐름

사진 → 구조 분석 → 부품 분해 → 관절/모터 선정 → 전자 시스템 → 소프트웨어 구조 → 3D CAD → 프로토타입 → 테스트/개선

## 파일

- `BOOK.md` : 오늘 영상 내용을 책 형식으로 정리한 본문
- `PROJECT_FILES.md` : 이미지와 파일 설명
- `images/` : 영상 및 설계 이미지
- `terminal_commands.sh` : GitHub 업로드용 터미널 명령 예시

## 참고

초기 AI 생성 도면에는 실제 MicroDuck과 다른 구조(예: 4족처럼 보이는 표현)가 포함될 수 있습니다. 이 프로젝트의 목적은 한 장의 사진에서 출발해 설계 아이디어를 빠르게 시각화하고, 시스템 전체를 이해하며, 반복적으로 개선하는 과정을 기록하는 것입니다.
