# AI와 함께 시작하는 일인 로봇 제조

MicroDuck 사례로 보는 사진 → 3D 모델 → CAD → 3D 프린팅 → 모터 → 소프트웨어·AI

이 프로젝트는 MicroDuck 같은 소형 로봇을 사례로, **AI와 디지털 제조 도구를 연결하면 개인 한 명이 로봇 제조에 어디까지 도전할 수 있는가**를 정리한 학습·제작 기록입니다.

## 전체 파이프라인

`이미지 → AI 구조 분석/정리 → Meshy AI → Blender → Onshape → 3D 프린팅 → DYNAMIXEL/전자부품 → 소프트웨어 제어 → 센서/AI 학습 → 실제 로봇`

## 도구별 역할

- **생성형 AI**: 이미지 정리, 구조 분석, 아이디어·코드 지원
- **Meshy AI**: 사진/텍스트에서 3D Mesh 초안 생성
- **Blender**: 3차원 모델을 자르고, 분리하고, 수정하는 디지털 작업실
- **Onshape**: 실제 치수, 모터 장착부, 관절축, 볼트 구멍과 Assembly를 만드는 정밀 CAD
- **3D 프린터**: 설계를 빠르게 물리 부품으로 제작하고 반복 검증
- **DYNAMIXEL 등 스마트 액추에이터**: 로봇 관절의 구동
- **소프트웨어·AI**: 관절 제어, 센서 피드백, 보행·균형·행동 학습

## 핵심 메시지

> AI가 제조를 대신하는 것이 아니라, 개인이 제조에 도전할 수 있는 길을 넓혀주고 있다.

> “내가 모든 기술을 알고 있는가?”보다 “나는 무엇을 만들고 싶은가?”가 점점 더 중요한 질문이 되고 있다.

## 주의

AI가 생성한 3D 형상은 실제 치수와 내부 구조를 정확히 재현한다는 보장이 없습니다. 실제 제작 시에는 모터 치수, 체결 구조, 강성, 간섭, 토크, 배선, 내구성, 안전성 등을 별도로 검증해야 합니다.
