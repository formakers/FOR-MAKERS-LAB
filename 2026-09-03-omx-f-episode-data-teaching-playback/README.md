# OMX-F Episode 데이터 수집과 자동 재생

사람이 키보드로 OMX-F 로봇팔을 움직여 시범 동작을 만들고, 이를 Episode CSV로 기록한 뒤 여러 Episode를 자동 재생하는 실습 프로젝트입니다.

## 핵심

- Terminal 1: OMX-F Bringup
- Terminal 2: Keyboard Teleoperation
- Terminal 3: `record_joint_data.py`
- Terminal 4: `play_all_episodes.py`
- 데이터: `episode_001.csv`, `episode_002.csv`, `episode_003.csv` ...

자세한 내용은 [BOOK.md](BOOK.md)를 참고하세요.
