# FOR MAKERS LAB | 촬영·방송·편집 환경 만들기

## 프로젝트 소개

FOR MAKERS LAB의 YouTube 제작 환경을 구축하는 과정을 기록한 프로젝트입니다.

이번 작업에서는 앞으로 제작할 AI·로봇·메이커 콘텐츠를 위해
촬영, 방송, 녹화, 영상 편집 환경을 구성하고 테스트했습니다.

단순히 영상을 촬영하는 것을 넘어,
한 편의 영화나 하나의 이야기처럼 기술과 제작 과정을 전달하는
FOR MAKERS LAB만의 영상 제작 방식을 만들어가는 첫 단계입니다.


## 이번 작업

- 방송용 마이크 세팅
- Insta360 카메라 세팅
- Logitech 웹캠 세팅
- OBS Studio 촬영 및 녹화 환경 구성
- OBS 화면과 자막 구성
- Kdenlive 영상 편집
- 배경음악 적용
- YouTube 영상 제작 및 업로드
